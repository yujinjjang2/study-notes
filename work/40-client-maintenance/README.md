# 고객사 유지보수

고객사 운영 중 접수된 문의·장애·설정 요청을 일반화해 기록한다. 특정 고객사나 담당자 단위로 폴더를 나누지 않고, 재사용 가능한 업무 주제별로 분류한다.

## 분류 원칙

- `organization-registration/`: 회사·조직·조합 등 운영 주체의 신규 등록, 연결, 코드 설정
- `incidents/`: 운영 중 발생한 오류의 원인, 조치 및 재발 방지
- `operations/`: 데이터 설정, 고객 안내, 운영 절차
  - `website-content/`: 홈페이지 메뉴·페이지·정적 자산 변경

한 이슈가 여러 분류에 걸쳐도 주된 처리 목적을 기준으로 한 곳에만 원본을 둔다. 고객명, 담당자, 계정, 연락처, 사업자등록번호, 운영 DB 식별값은 기록하지 않는다.
