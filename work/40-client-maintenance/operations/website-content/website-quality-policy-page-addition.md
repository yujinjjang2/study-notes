# 홈페이지 카테고리 추가 및 첨부파일 업로드

- Redmine: #36849
- 작업일: 2026-08-28
- 상태: 해결
- 성격: 고객사 유지보수 / 홈페이지 콘텐츠 변경

## 작업 요청

홈페이지 **연합회소개** 카테고리에 `품질방침`을 추가하고, 전달받은 품질방침 자료를 해당 페이지에 게시한다.

메뉴 위치는 기존 `공평성선언`과 `회원현황` 사이이다.

## 수정 대상

| 구분 | 수정 대상 | 작업 내용 |
| --- | --- | --- |
| 사이드 메뉴 | `View/Introduction/commonIntroductionMenu.jsp` | `품질방침` 카테고리 추가 |
| 상세 페이지 | `View/Introduction/qualityCourse.jsp` | 품질방침 신규 페이지 추가 |
| 페이지 이동 | `Script/common.js` | 품질방침 페이지로 이동하는 라우팅/함수 추가 |
| 이미지 | `Image/introduction/quality_course.jpg` | 전달받은 품질방침 이미지 배치 |

위 경로는 고객사 홈페이지 배포 디렉터리를 기준으로 한 상대 경로다. 실제 서버·볼륨 위치와 접속 정보는 내부 `Web Team_서버` 시트를 참조하며, 이 노트에는 기록하지 않는다.

## 작업 순서

1. 내부 서버 시트에서 대상 홈페이지의 배포 서버와 웹 루트를 확인한다.
2. 현재 연합회소개 메뉴의 항목 순서와 기존 품질방침 페이지 존재 여부를 확인한다.
3. `commonIntroductionMenu.jsp`에서 `공평성선언`과 `회원현황` 사이에 `품질방침` 메뉴를 추가한다.
4. `qualityCourse.jsp`를 추가하고 전달받은 품질방침 내용을 반영한다.
5. `common.js`에 신규 페이지 이동 경로를 등록한다.
6. 전달받은 이미지 파일을 `Image/introduction/quality_course.jpg`로 배치한다.
7. 메뉴 → 상세 페이지 → 이미지 표시 순서로 운영 화면에서 확인한다.
8. 작업 완료 내용을 고객에게 안내한다.

## 확인 항목

- `연합회소개`에서 `품질방침`이 지정된 순서로 노출되는지
- 메뉴 클릭 시 `qualityCourse.jsp`로 정상 이동하는지
- 품질방침 본문과 `quality_course.jpg`가 정상 표시되는지
- 기존 `공평성선언`, `회원현황` 메뉴와 페이지에 영향이 없는지
- 캐시를 비운 브라우저에서도 결과가 동일한지

## 작업 전 준비물

- 고객 전달 품질방침 원본 및 게시 승인본
- 최종 메뉴명과 메뉴 노출 순서
- 대상 서버의 접속 권한 및 배포 경로 확인 권한
