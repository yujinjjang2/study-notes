# 홈페이지 상단 메뉴 내 카테고리 추가

- Redmine: #36871
- 작업일: 2026-09-04
- 상태: 해결
- 성격: 고객사 유지보수 / 홈페이지 메뉴 변경

## 작업 요청

홈페이지 상단 메뉴 **연합회소개**의 하위 카테고리로 `품질방침`을 추가한다.

신규 메뉴를 클릭하면 품질방침 페이지로 이동해야 한다.

## 수정 대상

| 구분 | 수정 대상 | 작업 내용 |
| --- | --- | --- |
| 상단 공통 메뉴 | `View/Main/commonTop.jsp` | 상단 연합회소개 하위에 품질방침 카테고리 추가 |
| 페이지 이동 | 상단 메뉴의 링크 또는 이동 함수 | 품질방침 페이지로 연결 |

Redmine에 기록된 구현 예시는 다음과 같다.

```html
<a href="javascript:movePageToQualityCourse()">품질방침</a><br/>
```

실제 서버·볼륨 위치와 접속 정보는 내부 `Web Team_서버` 시트를 참조하며, 이 노트에는 기록하지 않는다.

## 작업 순서

1. 내부 서버 시트에서 대상 홈페이지의 배포 서버와 웹 루트를 확인한다.
2. 상단 공통 메뉴 파일에서 `연합회소개`의 하위 메뉴 구조를 확인한다.
3. `commonTop.jsp`에 품질방침 메뉴 항목을 추가한다.
4. `movePageToQualityCourse()` 또는 현재 사이트의 동등한 이동 방식이 품질방침 페이지를 가리키는지 확인한다.
5. 운영 화면에서 상단 메뉴 → 품질방침 메뉴 → 대상 페이지 이동을 확인한다.
6. 작업 완료 내용을 고객에게 안내한다.

## 확인 항목

- 상단 `연합회소개` 메뉴에 `품질방침`이 정상 노출되는지
- 신규 메뉴 클릭 시 품질방침 페이지로 정상 이동하는지
- 기존 상단 메뉴 항목의 순서, 링크, 스타일에 영향이 없는지
- 공통 헤더를 사용하는 주요 페이지에 레이아웃 깨짐이 없는지
- 캐시를 비운 브라우저에서도 메뉴와 링크가 정상인지

## 관련 작업

품질방침 상세 페이지·사이드 메뉴·이미지 배치는 [홈페이지 카테고리 추가 및 첨부파일 업로드](website-quality-policy-page-addition.md) 작업을 참조한다.
