# 업무 노트 작성 안내

새 업무 노트는 상위 `work/README.md`의 폴더 구조와 분류 규칙을 따른다.

## 권장 문서 형식

```markdown
# 문서 제목

- 상태: draft | confirmed | archived
- 작성일: YYYY-MM-DD
- 관련 영역: web | mobile | api | backend | report | integration

## 배경

## 확인한 흐름

## 판단 또는 해결 방법

## 검증 방법

## 관련 문서
```

민감 정보와 원본 코드 전문은 기록하지 않는다.

## SQL 코드 블록

- 새 SQL 예시는 사내 SQL 코딩 컨벤션을 따른다. Oracle 전통 조인 문법, `Where 1 = 1`, Title Case 키워드·함수, 후행 쉼표, `#{변수명}` 바인딩, 대문자 스네이크 케이스 컬럼 별칭, 한글 컬럼 주석을 적용한다. 원본 컬럼명과 같은 별칭은 생략하고 실제 컬럼명 표기(`CRTDATE` 등)를 유지한다.
- 실제 소스의 일부나 절차 코드처럼 독립 실행할 수 없는 내용은 `sql` 대신 `text` 코드 블록으로 표시하고, 원본 발췌임을 본문에 밝힌다.
